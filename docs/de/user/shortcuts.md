# Tastaturkurzbefehle

Jotter ist so konzipiert, dass es sich hocheffizient über Tastaturkurzbefehle bedienen und navigieren lässt.

> [!NOTE]
> Globale Tastenkombinationen werden automatisch deaktiviert, sobald du dich in Formularfeldern, Texteingabefeldern, Suchmasken oder Dropdown-Menüs befindest, um versehentliche Auslösungen beim Tippen zu verhindern.

---

## Globale Board-Kurzbefehle

Diese Tastenkombinationen sind aktiv, wenn du dich auf der Hauptansicht des Kanban-Boards befindest und keine Aufgabe bearbeitest.

| Tastenkombination | Aktion | Beschreibung |
| :--- | :--- | :--- |
| <kbd>q</kbd> | **Aufgabe erstellen** | Öffnet sofort das Formular zum Erstellen einer neuen Aufgabe in der Standardspalte. |
| <kbd>i</kbd> | **Aufgabe erfassen** | Öffnet von jeder Seite aus das Formular im Projekt, das unter *Einstellungen → Projekt für schnelles Erfassen* gewählt ist. Ohne gewähltes Projekt passiert nichts. <kbd>q</kbd> tut dasselbe auf einer Seite ohne eigenes Projekt. |
| <kbd>Umschalt</kbd> + <kbd>Q</kbd> | **Dringende Aufgabe erstellen** | Öffnet sofort das Formular zum Erstellen einer neuen Aufgabe, vorausgefüllt mit der höchsten Priorität (dringend), orangefarbener Kartenfarbe und für heute geplant. |
| <kbd>Strg</kbd> + <kbd>K</kbd> | **Aufgaben suchen** | Öffnet das globale Suchmenü, um Aufgaben zu durchsuchen und direkt zu ihnen zu navigieren. |
| <kbd>Strg</kbd> + <kbd>A</kbd> | **Alle auswählen** | Wählt alle aktuell sichtbaren Aufgaben auf dem Board aus. |
| <kbd>Escape</kbd> | **Auswahl aufheben** | Deselektiert alle aktuell ausgewählten Aufgaben auf dem Board. |

---

## Mit ausgewählten Aufgaben

Sind eine oder mehrere Aufgaben ausgewählt, öffnet eine Taste das passende Menü der Aktionsleiste. In einem geöffneten Menü wählen die Zifferntasten <kbd>1</kbd> bis <kbd>9</kbd> den Eintrag an dieser Stelle (nicht im Tag-Menü, wo du tippst).

| Tastenkombination | Menü |
| :--- | :--- |
| <kbd>t</kbd> | **Tags** |
| <kbd>p</kbd> | **Priorität** |
| <kbd>m</kbd> | **In Spalte verschieben** |
| <kbd>Umschalt</kbd> + <kbd>M</kbd> | **In Projekt verschieben** |
| <kbd>d</kbd> | **Fälligkeit** |
| <kbd>s</kbd> | **Geplantes Datum** |
| <kbd>c</kbd> | **Farbe** |

---

## Modals und Dialogfenster

Diese Tastenkombinationen gelten, wenn ein modales Dialogfenster (z. B. Aufgabendetails, Neuerstellung oder Einstellungen) geöffnet ist.

| Tastenkombination | Aktion | Beschreibung |
| :--- | :--- | :--- |
| <kbd>Escape</kbd> | **Schließen** | Schließt das aktive Dialogfenster und kehrt zum Board zurück. |
| <kbd>Strg</kbd> + <kbd>Enter</kbd> | **Speichern** | Speichert deine Änderungen im Editor der Aufgabendetail-Ansicht. |
| <kbd>Alt</kbd> + <kbd>D</kbd> | **Diktat umschalten** | Startet oder stoppt das Sprachdiktat in Titeleingabefeldern. |
